# Conex

A web platform for HR management with blockchain-based payment and billing modules.

Conex connects client companies, freelance engineers, and smart contracts on a single platform: case and hours tracking, client billing, and engineer payouts in a test stablecoin (ERC-20), deployed on an L2 network (Base Sepolia).

## Monorepo structure

- `contracts/` — Solidity smart contracts (Hardhat, OpenZeppelin)
- `backend/` — REST API (Node.js, Express, PostgreSQL, Prisma)
- `frontend/` — Web interface (React, Vite, wagmi, MUI)
